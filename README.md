# 👑 땅따먹기 배틀! (Land Rush Battle) 🤖

사용자와 컴퓨터가 번갈아 가며 빈 칸을 차지하는 실시간 땅따먹기 캐주얼 보드게임입니다.  
밝고 생동감 넘치는 3D 팝 디자인, 통통 튀는 애니메이션, Web Audio 사운드 및 승리 축하 폭죽 효과가 적용되어 있습니다.

---

## 🎮 게임 실행 방법

### 방법 1. 웹 브라우저에서 바로 열기 (가장 간단)
- `index.html` 파일을 더블 클릭하여 Chrome, Edge, Safari 등 원하시는 브라우저에서 즉시 실행하세요. (별도 설치 필요 없음)

### 방법 2. 로컬 웹 서버로 접속하기
- 현재 백그라운드 로컬 서버가 구동 중입니다:
  - 브라우저 주소창에 `http://localhost:8085/` 입력

---

## 🕹️ 게임 룰 & 주요 기능

1. **땅 차지하기**:
   - 비어 있는 하얀색 네모 타일을 클릭(터치)하면 **나의 영역(하늘색 왕관 👑)**으로 점령됩니다.
   - 내가 칸을 차지하면 즉시 컴퓨터가 남아 있는 빈 칸 중 하나를 선택하여 **컴퓨터의 영역(코랄핑크 로봇 🤖)**으로 점령합니다.
   - 이미 차지된 칸은 다시 클릭할 수 없으며, 컴퓨터가 고민 중인 동안에는 중복 입력이 차단됩니다.

2. **실시간 스코어 & 점유율 게이지**:
   - 상단 대시보드에서 나와 컴퓨터가 차지한 칸 수, 남은 빈 칸 수, 그리고 줄다리기 형태의 실시간 영토 점유율(%)을 확인할 수 있습니다.

3. **승패 판정 & 결과 모달**:
   - 보드의 모든 칸이 다 차면 게임이 종료됩니다.
   - 차지한 칸 수가 더 많은 쪽이 승리하며, 동점일 경우 무승부로 판정됩니다.
   - 승리 시 화려한 폭죽(Confetti) 파티클과 승리 팡파레 효과음이 재생됩니다!

4. **다양한 추가 옵션**:
   - **맵 크기 변경**: 4×4(16칸), 5×5(25칸 기본), 6×6(36칸), 7×7(49칸)
   - **컴퓨터 난이도**: 🎲 기본(완전 랜덤) / 🤖 똑똑이(자신의 영토를 뭉쳐서 확장하는 알고리즘)
   - **새 게임 버튼(🔄)**: 언제든 보드를 초기화하고 새로 시작
   - **사운드 On/Off 토글(🔊)**: 브라우저 내장 Web Audio API 신시사이저 기반의 통통 튀는 효과음
   - **전적 통계(🏆)**: 총 승리/무승부/패배 횟수와 승률 기록 및 초기화 기능
   - **PC & 모바일 반응형**: 스마트폰 터치 화면과 데스크톱 화면 모두에 최적화된 유연한 뷰포트 레이아웃

---

## 📁 파일 구조
- `index.html` : 게임 화면 구조, 점수 대시보드, 모달 팝업
- `style.css` : 밝고 생동감 넘치는 젤리 팝 & 글래스모피즘 테마 스타일링
- `app.js` : 게임 턴 로직, 인공지능 착수, Web Audio 신시사이저, 폭죽 캔버스 물리 엔진, 전적 로컬 저장소 연동
